# AI-ассистент для поиска музыки, фильмов и сериалов

## Описание
AI-ассистент для поиска музыки, фильмов и сериалов - это концепция интеллектуального помощника, который помогает пользователям находить музыку для любого момента жизни, фильмы для уютного вечера и сериалы, способные увлечь с первой серии.

Вместо бесконечного просмотра рекомендаций и десятков поисковых запросов пользователь сможет просто описать, что он хочет услышать или посмотреть, а искусственный интеллект поможет подобрать подходящие варианты исходя из его запроса и настроения.

Проект был разработан студентами в качестве индивидуального проекта для 1 курса специальности 02.03.02 "Фундаментальная информатика и информационные технологии".

## Схема работы программы

Программа поделена на 3 логические части:

1. Пользовательский интерфейс;
2. AI-обработка и рекомендации;
3. Поиск и работа с данными.
